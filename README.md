# Shopify Sales & Customer Funnel Dashboard

An interactive Power BI dashboard designed to analyze Shopify sales performance, customer purchasing behavior, retention, and regional sales patterns.

## Dashboard Preview

![shopify-sales-customer-funnel-dashboard](Screen shot/Shopify dashboard.PNG)

## Project Overview

This project transforms Shopify transactional data into an interactive business intelligence dashboard.

The dashboard brings together sales, customer, retention, regional, payment gateway, and product-level insights in a single view to support faster business analysis.

## Key Areas Analyzed

### Transaction Performance
- Net Sales
- Total Quantity
- Net Average Order Value

### Customer Purchase Behavior
- Total Customers
- Repeat Customers
- Single-Order Customers

### Retention & Value
- Lifetime Value
- Repeat Rate
- Purchase Frequency

### Sales Analysis
- Sales trends over time
- Sales by order hour
- Sales by billing address/province
- Sales by city
- Sales by payment gateway
- Sales by product type

## Dashboard Features

- Interactive KPI cards
- Dynamic KPI selection
- Gateway filtering
- Province filtering
- Interactive geographical analysis
- Sales trend analysis
- Customer behavior analysis
- Product and payment performance analysis
- Dedicated details page

## Tools & Technologies

- **Power BI**
- **DAX**
- **Power Query**
- **Data Visualization**
- **Business Intelligence**

## Business Questions

This dashboard helps explore questions such as:

- How are overall sales performing?
- Which locations generate the most sales?
- When are orders most frequently placed?
- How much of the customer base consists of repeat customers?
- Which payment gateways contribute the most sales?
- Which product types generate the highest sales?
- What does customer retention look like?

## Project Objective

The objective of this project is to turn raw transactional data into an intuitive and interactive dashboard that makes sales and customer behavior easier to understand and analyze.
